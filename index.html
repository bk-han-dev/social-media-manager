Step 2 of 8

Create your bot and connect X

Open the Grok app and create a new Grok Bot. Name it My X Manager.

In the bot's connections, connect X so it can read and research public posts. To let it post for you, also connect a posting tool such as Buffer linked to your X account.

On its own, the bot's X connection reads public X but can't post. Posting needs a posting tool (like Buffer), or your own X API developer keys (advanced; X API access may be paid). No posting tool? The bot gives you each ready post and image to copy and paste.

You're done with this step when you have a new, empty bot with X connected (and Buffer, if you want automatic posting).
